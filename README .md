## Proyecto destacado

### [TESOEM · Sistema de préstamos de materiales](https://github.com/AngelSeba/tesoem-prestamos-materiales)

Aplicación web para gestionar solicitudes, entregas, devoluciones parciales e inventario de materiales en un entorno escolar.

**Mi aportación:** desarrollo del backend con Google Apps Script, desarrollo de la API y creación de la estructura de las tablas de datos utilizadas en Google Sheets.

**Trabajo en equipo:** [giovas128-2](https://github.com/giovas128-2) desarrolló el frontend con HTML, CSS y JavaScript.

**Estado del repositorio:** código y documentación disponibles. Para ejecutar el sistema completo se requiere configurar un entorno propio de Google Apps Script y Sheets; todavía no hay una demo pública independiente.
